# Corrections

One file per correction you make to a bot's writing, named `<date>-<bot>-<slug>.md`. The Saturday prompt in Volume 4, Build 8 reads this folder and looks for patterns. Format:

```
bot: quill
channel: <email, post, client note, card comment>
before:
<what the bot wrote>
after:
<what you changed it to>
why:
<one sentence: too formal for the channel, invented a number, buried the ask, ...>
```

Three of the same "why" is a SOUL.md line. One is a note.
